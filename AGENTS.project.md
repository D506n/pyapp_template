# Правила генератора pyapp_template

Применять AGENTS.md и CODESTYLE.md этого репозитория. Это исходник Copier-шаблона,
не готовое приложение. Конфигурация генератора — copier.yml; содержимое создаваемого
проекта — template/. Язык генерируемого сервиса — Python 3.14, зависимости через uv.

Текущий согласованный объём: async FastAPI/FastMCP, SQLAlchemy с asyncpg/aiosqlite/asyncmy,
Alembic через async engine, опциональный httpx. Настройки: os.getenv(...) по умолчанию,
magutils.env или pydantic_settings. Magutils можно отдельно подключить при другом
способе настроек; по умолчанию он выключен. logging стандартный.
CI, Docker, Redis и автоматические миграции исключены.

Создаётся самостоятельный uv-проект с package=false и запуском main.py; код
разделён по назначению в src/, без именованного пакета приложения и wheel-сборки.
Последний вопрос позволяет явно согласиться на uv sync после copy. По умолчанию
установка выключена; update/pretend/skip-tasks её не выполняют. Git-команды и
миграции автоматически не запускаются. Ошибка установки не удаляет созданные файлы.
Секреты не входят в вопросы или ответы шаблона. Имя каталога не ограничивать
правилами имени Python-пакета; техническое имя metadata uv формируется отдельно.

Команда приёмки генератора — just precommit-check-agent; её состав определяется
локальной .justfile. Проверять как рендеринг вариантов, так и исполнение выбранных
сгенерированных проектов. Тесты принадлежат тестировщику; инфраструктурные рецепты
и скрипты — инфраструктурщику. Не считать вывод pytest очищенным от любых секретов.
Краткий отчёт Bandit — data/bandit-report-short.json; полный отчёт не выводить
в контекст агента. Отчёты и кэши не включать в Git.

Репозиторий для публикации — D506n/pyapp_template, лицензия MIT. Лицензия создаваемого
проекта выбирается отдельно. Не коммитить без одобрения состава человеком;
публиковать рабочую ветку, слияние выполняет человек. Не переписывать историю.
